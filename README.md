# Retail Sales & Business Performance Analysis

An end-to-end data analytics project focused on understanding retail sales performance, customer activity, product performance, and regional trends using **Excel, SQL, Python (Pandas), and Power BI**.

## Project Overview

Businesses generate large amounts of sales data, but raw data is not useful until it is cleaned, analyzed, and converted into clear business insights.

In this project, retail sales data is processed from raw data to final reporting. The workflow covers:

1. Data cleaning and preparation
2. Exploratory analysis
3. SQL-based business analysis
4. Excel reporting
5. Python/Pandas data processing
6. Power BI dashboard development
7. Business insights and recommendations

## Business Objectives

* Measure overall sales performance
* Track monthly sales trends
* Identify top-performing products and categories
* Compare regional performance
* Monitor order and customer activity
* Identify data quality issues such as duplicates and missing values
* Create business-friendly reports and dashboards
* Convert raw data into actionable insights

## Dataset

The project uses a retail sales dataset containing business transaction information such as sales, customers, products, categories, regions, quantities, and dates.

Dataset location:

`Dataset/retail_sales.csv`

## Project Workflow

### 1. Data Cleaning

The raw dataset is checked for:

* Missing values
* Duplicate records
* Incorrect data types
* Invalid or inconsistent values
* Date formatting issues
* Calculation errors

### 2. Excel Analysis

Excel is used to create structured reports using:

* SUM and related formulas
* SUMIFS / COUNTIFS
* XLOOKUP / VLOOKUP where required
* Sorting and filtering
* Pivot Tables
* Charts
* KPI summaries

Excel file:

`Excel/Retail_Sales_Analysis.xlsx`

### 3. SQL Analysis

SQL is used to answer business questions such as:

* What is the total sales amount?
* How many orders were placed?
* Which products generate the highest sales?
* Which regions perform best?
* What are the monthly sales trends?
* Which categories contribute the most revenue?

SQL file:

`SQL/retail_sales_analysis.sql`

### 4. Python Analysis

Python with Pandas is used for repeatable data preparation and analysis.

Main activities include:

* Loading the CSV dataset
* Inspecting rows and columns
* Checking missing values
* Removing duplicates
* Converting data types
* Creating calculated fields
* Performing basic statistical and trend analysis

Python notebook:

`Python/data_cleaning_analysis.ipynb`

### 5. Power BI Dashboard

The Power BI dashboard is designed to provide an interactive business view of the dataset.

Suggested KPIs:

* Total Sales
* Total Orders
* Total Customers
* Total Quantity
* Average Order Value

Suggested visualizations:

* Monthly Sales Trend
* Sales by Region
* Sales by Category
* Top Products
* Customer/Order Analysis
* Interactive slicers for Date, Region and Category

Power BI file:

`PowerBI/Retail_Sales_Dashboard.pbix`

## Key Business Questions

1. Which month generated the highest sales?
2. Which region contributes the most revenue?
3. Which products are the top performers?
4. Which categories need attention?
5. Are sales increasing or decreasing over time?
6. What is the average order value?
7. Are there any duplicate or missing records affecting the report?
